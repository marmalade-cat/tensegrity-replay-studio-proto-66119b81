TensegrityReplayStudio - prototype

A compact web prototype that:
- Loads per-module trajectories from CSV or JSON
- Validates basic consistency (time monotonicity, consistent module count and fields)
- Shows interactive plots and an animated 3D wireframe viewer
- Exports a normalized replay JSON

Usage: open index.html in a modern browser. Example files can be loaded from the "Load example" menu.

Notes: This is an untested, small prototype demonstrating the workflow. No external libraries used; WebGL is built-in to browsers.
